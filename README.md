# VibroRoad — Система мониторинга дорожного покрытия

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 📖 Описание проекта

**VibroRoad** — это распределенная система для мониторинга и анализа качества дорожного покрытия с использованием IoT-устройств на базе ESP32. Система собирает данные о вибрации транспортного средства, обрабатывает их и визуализирует на тепловой карте для выявления проблемных участков дорог.

##  Компоненты

### 1. **ESP32 Устройство** (`esp/`)
Микроконтроллер с датчиками для сбора данных:
- **IMU MPU-6050** — акселерометр и гироскоп для измерения вибрации
- **GPS-модуль** — геолокация и скорость
- **Wi-Fi** — отправка данных на сервер

**Характеристики:**
- Частота дискретизации: 20 Гц
- Окно сбора данных: 2 секунды
- Вычисляемые метрики: RMS, P95, Max ускорения, Jerk

### 2. **Backend** (`backend/main/`)
Серверная часть на Python:
- **FastAPI** — REST API
- **PostgreSQL + PostGIS** — хранение и обработка геоданных
- **Psycopg** — работа с БД
- **NumPy/Pillow** — генерация тепловых карт

**Основные endpoints:**
- `POST /ingest/windows` — приём данных от ESP32
- `GET /heatmap` — генерация тепловой карты
- `GET /heatmap_lines` — визуализация треков
- `GET /health` — проверка подключения к БД

### 3. **Telegram Bot** (`ui/`)
Интерфейс для пользователей:
- **aiogram** — асинхронный бот
- Запрос вибрационных данных по локации
- Отображение тепловых карт
